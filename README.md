# 🛡️ Tank Tactics: Zırhlı Muharebe

HTML5 Canvas, CSS3 ve saf JavaScript (Vanilla JS) kullanılarak geliştirilmiş, Web Audio API ses sentezleyici motoruna ve vektörel render sistemine sahip gerçek zamanlı taktiksel hat savunma oyunu.

## 🎮 Temel Özellikler
* **Vektörel Çizim Motoru:** Dış görsel bağımlılığı olmadan Canvas API ile çizilen gövde ve bağımsız dönen taretler.
* **Gelişmiş Balistik & Fizik:** Mermi sekmesi (ricochet), palet kırılması (kritik hasar), mermi izleri ve namlu geri tepmesi.
* **Taktiksel Harita Unsurları:** Yıkılabilir beton siperler ve alev alev yanan kalıcı tank enkazları.
* **Ekonomi & İksir Sistemi:** Zamanla ve yok edilen her düşmandan kazanılan enerji (iksir) döngüsü.
* **Komutan & Kışla İlerlemesi:** Düşman imha ettikçe kazanılan XP ile seviye atlama, yeni askeri sınıfları (Piyade, Uçaksavar, MLRS, Plazma) açma ve hurda ile kalıcı geliştirme (LocalStorage).
* **3 Farklı Biyom (Harita):** Bozkır, Kutup ve Lav Krateri haritaları.
* **Dinamik Ses Motoru:** Dış ses dosyası indirmeden osilatörlerle üretilen prosedürel ateş, patlama, telsiz ve hava saldırısı sesleri (Web Audio API).

## 🛠️ Kullanılan Teknolojiler
* **HTML5 Canvas** (2D Rendering Context)
* **JavaScript** (ES6+, Web Audio API, LocalStorage)
* **CSS3** (Flexbox, Glassmorphism UI)
